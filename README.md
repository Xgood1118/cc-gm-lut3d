# lut3d

纯标准库实现的 3D LUT（`.cube`）解析与三线性插值调色器。

## 使用

```bash
python -m lut3d.cli data/lut.cube --out graded.json
```

`--out` 会把统计结果写成 JSON；`--width/--height` 调整验证图尺寸；`--bench` 会额外跑
2 倍边长的图像，检查耗时随像素数增长是否接近线性。

```python
import lut3d as m

lut = m.load_cube("data/lut.cube")          # -> LUT3D
out = m.apply_lut(lut, (0.25, 0.2, 0.1))    # 单像素 -> (r, g, b)
outs = m.apply_lut(lut, image)              # 像素序列 -> [(r, g, b), ...]
err = m.measure_error([(outs[i], refs[i])]) # -> 最大逐通道绝对误差
```

## 实现要点

### 解析（`load_cube`）

- 支持 `LUT_3D_SIZE`、`DOMAIN_MIN` / `DOMAIN_MAX`、`LUT_3D_INPUT_RANGE`、
  `TITLE`；`#` 之后的内容（含行尾注释）与空行全部跳过。
- 数据顺序遵循 `.cube` 约定：**红色变化最快，其次绿色，蓝色最慢**，
  即 `index = r + g * size + b * size²`。
- 声明尺寸与实际数据行数不一致（少了或多了）、缺少 `LUT_3D_SIZE`、重复声明、
  数值非有限或列数不对时一律抛 `ValueError`；**绝不截断，也绝不补零**。
- `LUT_1D_SIZE` 等一维指令直接报错，不静默忽略。

### 应用（`apply_lut`）

- 严格三线性：对每个通道把输入线性映射到格点坐标，取相邻 8 个角点按
  8 个权重加权求和（三通道共用同一组权重）。不会退化为最近邻。
- 输入先钳制到 `[DOMAIN_MIN, DOMAIN_MAX]`：低于下界取下界、高于上界取上界，
  不回绕；`NaN` 按下界处理，`±inf` 按对应端钳制，因此输出永远是有限值。
- `1×1×1` 的 LUT 没有可插值的邻点，对域内任何输入都返回该唯一颜色。
- 接受单像素 `(r, g, b)` 或任意像素可迭代对象；批量调用只建一次插值闭包，
  逐像素内联求值，不产生临时列表。

### 误差口径（`measure_error`）

`measure_error(pairs)` 的 `pairs` 是 `(预测值, 参考值)` 的可迭代对象，
返回

```
max( |predicted[c] - expected[c]| )  遍历所有样本与所有通道
```

即 **L∞ / 最大逐通道绝对误差**，单位与 LUT 输出一致（通常是归一化的 0–1；
若输出是 8 bit，则误差也是 8 bit 刻度）。空输入返回 `0.0`，
出现 `nan/inf` 误差返回 `inf`，维度不匹配、分量非数值抛 `ValueError`。

CLI 里的 `max_error` 用同一口径：`data/lut.cube` 是恒等 LUT，参考值取
“输入钳制到域内”，因此这个数字同时校验了插值精度与钳制语义。

## 实测结果

`python -m lut3d.cli data/lut.cube --out graded.json`（512×512 验证图，
每通道覆盖 −0.1…1.1，故意包含域外像素；Windows 11 / CPython，单线程）：

| 指标 | 数值 |
| --- | --- |
| `max_error` | `2.22044604925e-16`（约 2 ulp，可视为 0） |
| `clamped_pixels` | `111135 / 262144`（42.4% 的像素至少一个通道在域外） |
| `elapsed_seconds` | `0.81 s` |

规模与线性：

| LUT | 图像 | 像素数 | `apply_lut` 耗时 |
| --- | --- | --- | --- |
| 33³ | 256×256 | 65 536 | 0.23 s |
| 33³ | 512×512 | 262 144 | 0.98 s |
| 33³ | 1024×1024 | 1 048 576 | 3.80 s |
| 33³ | 512×512（`--bench` 实测） | 262 144 | 0.95 s |

像素数每次 ×4，耗时约 ×4（0.227 → 0.984 → 3.803），没有超线性跳变；
512×512 配 33³ 约 1 s，远低于 5 s 上限。

## 边界行为

| 情况 | 结果 |
| --- | --- |
| `1×1×1` LUT | 任何输入都返回该唯一颜色 |
| 域含负值（如 `[-1, 1]`） | 按格点坐标正常插值；`-1` 与 `+1` 精确落在两端节点 |
| 纯黑 `(0,0,0)` / 纯白 `(1,1,1)` | 恒等 LUT 下逐值不变；域外纯黑纯白钳制到端点后同样确定 |
| 域外输入、`NaN`、`±inf` | 钳制处理后返回有限值，绝不 NaN、绝不回绕 |
